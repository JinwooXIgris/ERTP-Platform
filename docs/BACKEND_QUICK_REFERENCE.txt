┌──────────────────────────────────────────────────────────────────────────────┐
│ EVERY ENDPOINT MUST FOLLOW THIS ORDER                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  1. require_method('POST');           ← Check HTTP method
  2. require_login();                  ← Check auth (if needed)
  3. require_role('admin');            ← Check role (if needed)
  4. $data = read_json();              ← Read and parse input
  5. $email = valid_email(...);        ← Validate input
  6. [Database queries with prepared statements]
  7. ok(...) or fail(...)              ← Return via response.php


┌──────────────────────────────────────────────────────────────────────────────┐
│ SECURITY RULES (NON-NEGOTIABLE)                                            │
└──────────────────────────────────────────────────────────────────────────────┘

✓ Use prepared statements for ALL database queries (no string concatenation)
✓ Hash passwords with password_hash() (BE-A in register.php)
✓ Validate all input server-side (never trust browser)
✓ Never expose raw database errors to users (log internally)
✓ Check HTTP method at the top of every endpoint
✓ Check auth/role for protected endpoints
✓ Use HttpOnly and SameSite cookies (in auth.php session setup)
